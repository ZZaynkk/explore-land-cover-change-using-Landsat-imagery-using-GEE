# GISCI241 — Project Images and Captions

Toshka–Lake Nasser region, southern Egypt.

This collection contains 12 original project images and their captions. Image contents are unchanged; filenames identify the year and image type. Code and statistical data files are not included.

## Caption provenance

The first four images are labelled 2013, 2018, 2019 and 2024 according to the confirmed upload order. The subsequent three classification images are labelled 2019, 2018 and 2013. The NDVI and MNDWI images are labelled 2024 based on the associated analysis stage; the screenshots themselves do not display a year.

The first four images belong to the exploratory full-year compositing workflow. The later images belong to the classification analysis stage. These compositing windows should not be treated as interchangeable.

## Legends

- **True colour:** Landsat 8 bands B4, B3 and B2 displayed as red, green and blue.
- **NDVI:** Brown represents lower values; pale colours through teal represent higher values. The display range in the source code is −0.2 to 0.8.
- **MNDWI:** Brown represents lower values and teal represents higher values. The display range in the source code is −0.6 to 0.6.
- **Preliminary land cover:** Light tan = Other; green = Vegetation; blue = Water. Water is classified where MNDWI > 0. Non-water pixels with NDVI > 0.2 are classified as Vegetation; remaining valid pixels are Other.
- **Land-cover changes:** Green = Other → Vegetation; blue = Other → Water; orange = Vegetation → Other; purple = Vegetation → Water; golden yellow = Water → Other; pink = Water → Vegetation. Unchanged pixels are masked, exposing the basemap. Basemap colours do not represent change classes.

These images are map screenshots, not georeferenced raster datasets. The classification is a preliminary threshold-based result without independent accuracy validation. Other is not exclusively bare land, and Vegetation does not represent all farmland.
